Recursos

Endpoints disponíveis

Todos os endpoints seguem o padrão REST e retornam JSON.

GET /health Verifica disponibilidade da API
GET /assets Lista todos os ativos cadastrados
GET /assets/:id Busca um ativo por ID (404 se não existir)
POST /assets/:id/telemetry Registra leitura de sensor com classificação automática
GET /assets/:id/telemetry Lista leituras de um ativo
GET /assets/:id/summary Resumo operacional agregado
GET /alerts Lista alertas gerados automaticamente
Regra de negócio

Classificação de temperatura

Cada leitura de telemetria é classificada automaticamente. Se for WARNING ou CRITICAL, um alerta é gerado e fica disponível em /alerts.

Normal
temperatureC < 75
Operação dentro do esperado. Nenhum alerta gerado.
Warning
75 ≤ temperatureC < 85
Temperatura acima do limite de atenção. Alerta criado automaticamente.
Critical
temperatureC ≥ 85
Temperatura em nível crítico. Alerta urgente criado automaticamente.
Exemplo

Registrar telemetria

Envie uma leitura de sensor. A resposta já inclui a classificação calculada.

POST /assets/WT-001/telemetry 
// Requisição
{
  "powerMw":       2.5,
  "temperatureC":  80,
  "windSpeedMs":   10.2,
  "timestamp":     "2026-09-13T12:00:00.000Z"
}

// Resposta 201 — classificação calculada automaticamente
{
  "powerMw":       2.5,
  "temperatureC":  80,
  "windSpeedMs":   10.2,
  "timestamp":     "2026-09-13T12:00:00.000Z",
  "severity":      "WARNING"
}
